# 📉 Customer Churn Analysis

> Data Analytics project focused on understanding customer churn behavior and identifying retention patterns using Python and visualization techniques.

## 🎯 Problem Statement

Customer churn directly affects business growth and revenue.
This project analyzes customer behavior to identify factors influencing churn and improve retention strategies.

## ⚡ Quick Demo

Input: Customer Dataset with Demographics & Subscription Details
Output: 📊 Churn Trends + 📈 Retention Insights + ⚠️ High-Risk Customer Identification

## 🛠️ Tech Stack

* Python
* Pandas
* Matplotlib
* Data Visualization & Analytics

## 📊 Analysis Performed

| Analysis Type              | Description                        |
| -------------------------- | ---------------------------------- |
| Churn Rate Calculation     | Measured overall churn percentage  |
| Gender-Based Churn         | Compared churn behavior by gender  |
| Contract Type Analysis     | Evaluated impact of contract plans |
| Customer Behavior Analysis | Identified retention patterns      |
| Tenure Analysis            | Studied customer loyalty trends    |

## 📈 Key Insights

* Identified customers with high churn probability
* Contract type significantly impacts customer retention
* Longer customer tenure improves retention rates
* Customer behavior patterns help predict churn risk
